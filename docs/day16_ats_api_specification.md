# Day 16 - ATS API Specification

## Objective

The objective of Day 16 is to design REST APIs that allow backend systems to consume the Zecpath ATS AI modules.

The APIs support:

- Resume upload
- Resume parsing
- ATS scoring
- Candidate shortlisting
- Async job tracking
- Error handling
- Logging standards
